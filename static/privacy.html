수집하는 정보와 목적

VEdit은 동영상 편집, 자막 작성, 파일 내보내기 및 사용자가 선택한 플랫폼 게시를 지원합니다. Google 로그인 시 계정을 구분하기 위한 이메일과 기본 프로필 정보를 처리합니다. 업로드 또는 저장 기능을 이용하면 동영상, 오디오, 이미지, 프로젝트, 자막과 파일 이름을 처리합니다. 음성 인식 기능은 선택한 미디어의 음성을 처리해 자막과 대본을 만듭니다.

YouTube 및 TikTok 연결

YouTube API Services를 사용합니다. 사용자가 연결에 동의하면 YouTube 업로드 권한과 채널 조회 권한으로 대상 채널을 확인하고 선택한 영상을 업로드합니다. 채널 ID, 채널 이름, 인증 토큰 및 게시 처리에 필요한 결과 정보를 처리합니다. TikTok 연결 기능이 활성화된 경우 기본 프로필과 동영상 게시 권한으로 계정, 허용 공개 범위, 상호작용 설정 및 게시 상태를 확인하고 선택한 영상을 보냅니다. 계정 비밀번호는 VEdit에서 수집하지 않습니다.

동영상, 제목, 설명, 공개 설정 및 관련 게시 정보는 사용자가 게시를 확인한 플랫폼으로 전송됩니다. 연결만으로 자동 게시하지 않습니다. Google과 TikTok은 전송받은 정보를 각자의 정책에 따라 처리합니다. Google 개인정보처리방침 · TikTok 개인정보처리방침.

저장 및 보관

기기 편집용 파일과 프로젝트 정보는 브라우저 저장소에 남을 수 있습니다. 서버 처리나 저장 기능으로 보낸 미디어와 프로젝트는 해당 계정의 서버 작업 공간에 저장될 수 있습니다. 임시 처리 대상으로 표시된 서버 파일은 24시간 후 정리 대상이 됩니다. 모든 저장 파일이 24시간 후 삭제되는 것은 아닙니다. 인증 토큰은 서버에서 암호화해 보관하며 브라우저 화면이나 프로젝트에 포함하지 않습니다. 게시 작업 상태는 작업 확인에 사용됩니다.

로그인 세션과 연결 검증을 위해 쿠키를 사용하고, 편집 데이터와 환경설정을 위해 브라우저 저장소를 사용합니다. Google 로그인 세션의 기본 유효기간은 7일입니다. 필요한 서비스 운영 외의 광고 추적이나 개인정보 판매를 목적으로 데이터를 사용하지 않습니다. Google API로 받은 사용자 데이터는 일반 AI 모델 학습에 사용하지 않습니다.

연결 해제, 삭제 및 문의

편집기에서 YouTube 또는 TikTok 연결을 해제할 수 있습니다. TikTok 연결 해제는 TikTok 권한 철회와 VEdit의 연결 정보 삭제를 요청합니다. YouTube 연결 해제는 VEdit에 저장된 연결 정보를 제거하며, Google의 권한도 제거하려면 Google 계정의 앱 권한 관리에서 VEdit의 접근 권한을 취소하세요. 이미 게시한 영상은 각 플랫폼에서 직접 관리하거나 삭제해야 합니다.
